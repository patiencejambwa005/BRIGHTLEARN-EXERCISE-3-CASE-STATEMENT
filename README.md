# BRIGHTLEARN-EXERCISE-3-CASE-STATEMENT
This project is part of my Data Analytics journey with Brightlearn.It focuses on SQL CASE statements and how they can be used to classify categorize  and analyze data based specific conditions.
OBJECTIVES
*Understand how the SQL CASE statement works 
*Use WHEN and THEN to create conditions
*Use ELSE and END to complete a CASE statement 
*Classify data into different categories
*Display results using meaningful column name 
TECHNOLOGIES USED
*SQL
*SQL Editor Database Platform
*GitHub for storing and sharing the assignment 

This assignment helpedme improve my SQL skills and understand how conditional logic can be used to organize and interpret data,these skills are useful in data analysis and reporting
